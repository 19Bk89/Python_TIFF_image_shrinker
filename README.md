# Python_TIFF_image_shrinker

Ein einfacher **TIFF-Bildmanager** in Python, der es dem Benutzer ermöglicht, TIFF-Bilder zu laden, deren Skalierungsfaktor zu berechnen und das Bild basierend auf diesem Faktor zu skalieren. Das Programm zeigt sowohl die Original- als auch die skalierte Bildgröße sowie die Dateigröße an und ermöglicht es dem Benutzer, das skalierte Bild an einem benutzerdefinierten Speicherort zu speichern.

## Funktionen

- **Bild laden**: Wählen Sie eine TIFF-Datei aus und laden Sie sie in das Programm.
- **Bild skalieren**: Geben Sie einen Skalierungsfaktor ein und berechnen Sie die neue Bildgröße und Dateigröße.
- **Skalierte Bildgröße anzeigen**: Zeigt die neue Dimension und Dateigröße des skalierten Bildes an.
- **Speichern**: Speichern Sie das skalierte Bild an einem benutzerdefinierten Speicherort.
